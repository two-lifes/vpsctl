# vpsctl

Консольное TUI-приложение на Go для управления VPS и деплоя проектов по SSH: обзор ресурсов, сервисов, проектов в `/opt`, доменов и SSL; bootstrap нового сервера по единому стандарту; деплой проектов из Git-репозиториев через Docker Compose.

**Статус:** подготовка. Продуктового кода пока нет.
